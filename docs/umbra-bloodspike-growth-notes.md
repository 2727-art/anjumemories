# BLOOD SPIKE 成長要望メモ — Phase 6の未承認候補

2026-09-06。ユーザーから示されたBLOOD SPIKEの成長要望を、将来の正式Stage成長を検討するために記録する。ここでいうPhase 6は開発段階であり、プレイヤーLvやDepth6を意味しない。このメモは実装指示や性能の承認ではなく、Phase 6への着手・自動進行も承認しない。

現行の根拠は [Phase 4実装・検証報告](umbra-phase4-report.md)。現在の検証S1は、固定した地面位置から半径80ワールドpxの瞬間範囲攻撃であり、突き上げ時に条件を満たす複数の敵へ命中する。近い敵1体を選ぶのは設置位置を決めるためで、命中対象を1体へ限定する仕様ではない。このS1の複数命中を維持したうえで、武装のStage成長による範囲拡大を検討する。

| 武装Stage | 攻撃半径の候補 | 位置づけ |
|---|---:|---|
| S1 | 80px | 現在の検証S1の半径を基準として維持する案。正式S1の性能確定ではない |
| S4 | 110px | Phase 6で検討する未承認候補 |
| S6 | 135px | Phase 6で検討する未承認候補 |
| S8 | 160px | Phase 6で検討する未承認候補 |

数値は半径であり、直径ではない。S2・S3・S5・S7の半径、段階間の補間や増加方法は未確定とし、表から自動的に埋めない。プレイヤーLvの上昇やDepth到達だけで半径が広がる案ではない。どのStageで何を取得・強化するかは、正式成長を扱う別の承認で決める。

探索距離600pxは、プレイヤーbody中心から設置候補を探すための距離として、攻撃半径と分けて扱う。80→110→135→160の案によって探索距離も自動拡大することはない。命中判定は固定地面点と敵の実円／矩形bodyの関係を基準とし、プレイヤー半径22や画像の透明余白を追加しない。範囲拡大を理由に壁内設置・壁越し攻撃・場外攻撃を許可しない。

半径を将来変更するときも、生成済みcastの地面位置と半径は生成時の値で固定する。Stage更新が起きても、すでに出た角を拡大・移動させず、新しい値は次に生成するcastから反映する。元標的や機体の移動へ追従する攻撃にも変えない。

判定半径と地面の表示を対応させ、どこまで突き上げが届くかを確認できるようにする。画像全体の縦横拡大だけで範囲が増えたと扱わず、地面の広がり、角の接地点、ガイド、敵の実shapeとの対応を確認する。角の高さや光・粒子の外縁は、そのまま攻撃半径の証明にはしない。現行の素材Previewの矩形・pivot・表示設定を、このメモに基づいて変更することもない。

将来一つのcastに複数の角を表示する案を検討する場合も、角の数・表示コマ数・重なりをダメージ回数にしない。同一castIdと同一lifeIdの組み合わせは最大1回の試行を維持し、受付を拒否された敵へ残りの角やコマで再試行しない。別castの独立した命中と区別する。複数角の生成数・配置・演出そのものは、このメモでは承認・確定しない。

成長を評価する際は、範囲・威力・周期・同時存在数を一括で強化しない。半径を広げるだけでも複数敵を巻き込む機会が増えるため、まず変更した項目の効果を分けて比べる。現行S1のraw基礎5、発動1800msとFire Control下限500ms、同時3castは現在の検証値であり、この半径案に合わせた一斉強化や、正式性能への採用を意味しない。

役割の検討では、MOONLIGHTの「有効ブーストで自分から敵の側面を通過して斬る攻撃」と、BLOOD SPIKEの「ブーストに依存せず固定地面点を単発で突き上げ、複数敵を巻き込む攻撃」を分ける。SPIKEの範囲成長によってMOONLIGHTの移動・通過操作を不要にする方向へ偏らないかを確認する。PHANTOM NOVAとの役割分担も、同武装の実攻撃を設計する段階で別途確認する。SPIKEの拡大案を根拠に、NOVAの代替となる持続攻撃・放電等を追加したり、NOVAの具体的性能まで確定したりしない。

他Stageの内容、威力、発動周期、同時存在数、Mutation、TRIAD、他武装との成長配分は未確定。この記録だけで正式な`stages`、取得カード、パッシブ、保存形式へ反映しない。実装するときは、別途承認された範囲で判定・表示・説明・候補・上限を揃えて確認する。

今回の感想と成長要望は、今後の検討材料として扱う。Phase 4の全項目、全端末、全fixture、実戦バランス、滑らかさ、正式性能の合格へ読み替えない。Phase 4報告に残る大きな遅延、角脱出の断続失敗、角での保守的な経路除外、未確認条件の記録を維持する。このメモの作成ではゲームソース・正式Stage・カード・保存・過去報告を変更せず、ブラウザ試験や外部通信も行わない。
